等待事件标志

参数
[in]trigger事件触发条件，取值：
  • 电平触发
    • Trigger::FlgSetAll : 掩码中的所有位同时为1
    • Trigger::FlgSetAny : 掩码中的任意位为1
    • Trigger::FlgClearAll : 掩码中的所有位同时为0
    • Trigger::FlgClearAny : 掩码中的任意位为0
  • 边沿触发
    • Trigger::FlgToggleAll : 掩码中的所有位同时发生翻转
    • Trigger::FlgToggleAny : 掩码中的任意位发生翻转
[in]consumption事件触发后是否清除事件：
  • 当 trigger 为 电平触发 时，
    • true 表示清除事件标志
    • false 表示保留事件标志
  • 当 trigger 为 边沿触发 时，此参数没有意义
[in,out]origin指向缓冲区的指针：
  • 当 trigger 为 电平触发 时
    • (O) 返回事件 触发之后，清理之前 的位图状态。 “**清理**” 是指 consumption 为 true 时，自动清除事件标志。
  • 当 trigger 为 边沿触发 时
    • (I) 输入时，作为评估事件位图是否发生变化的初始状态
    • (O) 输出时，返回触发后的事件标志位图状态（可作为下一次调用的初始值）
[in]msk事件的位图掩码，表示只关注掩码部分的事件
[in]mode等待模式，取值 Flg::WaitMode ：
  • Flg::WaitMode::FlgWait
  • Flg::WaitMode::FlgWaitTimed
  • Flg::WaitMode::FlgWaitUninterruptable
  • Flg::WaitMode::FlgTryWait
[in]to期望唤醒的时间点， 仅当 mode == Flg::WaitMode::FlgWaitTimed 时有效。
返回
错误码
返回值
XWOK没有错误
-EFAULT空指针
-ETIMEDOUT超时
-EINTR等待被中断
-ENOTTHDCTX不在线程上下文中
注解
  • 上下文：
    • mode == Flg::WaitMode::FlgTryWait : 任意
    • mode != Flg::WaitMode::FlgTryWait : 线程
  • 等待分为下列几种模式：
    • Flg::WaitMode::FlgWait: 调用线程会阻塞等待。
    • Flg::WaitMode::FlgWaitTimed 定时等待模式， to 表示等待超时的时间点：
      • to 通常是未来时间点，即 当前系统时间 + delta ， 可以使用 xwtm_ft(delta) 表示；
      • 如果 to 是过去的时间点，将直接返回 -ETIMEDOUT 。
    • Flg::WaitMode::FlgWaitUninterruptable 不可中断等待模式。
    • Flg::WaitMode::FlgTryWait 尝试模式（只测试不等待）。
