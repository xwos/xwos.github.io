XWOS®, developed since 2015, is a general-purpose real-time operating system running on embedded microcontrollers, primarily targeting reliable, real-time, and safety-critical application domains including automotive, IoT, and industrial control.

XWOS source code follows the MISRA-C:2012 standard and has been adopted in an increasing number of mass-production automotive projects.
